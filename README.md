# BDPL LabTools

Tools for the Born-Digital Preservation Lab (BDPL) at Stanford Libraries.

## Status

Early scaffolding. Nothing to install or run yet.

## Working rules

Everyone building here, human or AI, works by [CLAUDE.md](CLAUDE.md). Read it first.

## Layout

- `tools/` – catalog of lab applications, each in its own `bdpl-labtools-<app>` repo (see [tools/README.md](tools/README.md))
- `docs/` – procedures and notes
